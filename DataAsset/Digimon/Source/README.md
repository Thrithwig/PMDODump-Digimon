# Pinned user-supplied Cyber Sleuth dataset

These five CSV files were supplied from the user's local `For AI` folder and copied
without modification. The dataset is Liane Brisebois's Digimon Cyber Sleuth Dataset:
https://www.kaggle.com/datasets/lianebrisebois/digimon-cyber-sleuth-dataset

The original download date and publisher version were not supplied. The generated
manifest records them as unknown and pins each file by SHA-256. The importer never
downloads source gameplay data or silently changes these files. See
`docs/DIGIMON_DATA_PIPELINE.md` for normalization decisions and reproduction commands.
